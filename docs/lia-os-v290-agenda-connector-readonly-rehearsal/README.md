# LÍA O.S. v2.9.0 — Agenda Connector Read-Only Rehearsal

## Objetivo

Ensayar cómo se verían eventos de agenda dentro del conector, sin activar una fuente real.

## Experiencia visible

La tarjeta **Conector de Agenda** mantiene una vista simple y humana:

- Ensayo de lectura listo
- Lectura ensayada
- Eventos preparados
- Sin conexión real
- Aprobación pendiente

## Detalles

El usuario puede abrir **Ver detalles** para revisar tres eventos simulados de agenda.

## Auditoría

El usuario puede abrir **Ver auditoría** para ver tres confirmaciones simples de seguridad.

## Límites

- Sin red externa
- Sin credenciales reales
- Sin backend nuevo
- Sin escritura real
- Sin acciones reales
- Sin tarjeta técnica adicional
