## Qué NO representa todavía

Esta versión no debe venderse como sistema operativo real conectado.

Todavía no incluye:

- APIs reales.
- Acciones reales.
- Conectores reales activos.
- Voz real.
- WhatsApp real.
- Automatizaciones reales.
- Memoria persistente real.
- Integración real con calendario/correo/documentos.
- Backend operativo de producción para decisiones reales.
