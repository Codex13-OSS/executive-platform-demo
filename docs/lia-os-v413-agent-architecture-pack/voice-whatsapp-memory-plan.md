# Voice, WhatsApp & Memory Plan

## Voz

La voz será una capa futura de presencia ejecutiva.

Antes de usar voz real se debe definir:

- Permisos del navegador.
- Estados visuales.
- Confirmación antes de escuchar.
- Modo privacidad.
- Fallback sin voz.
- No activar escucha permanente en primeras versiones.

## WhatsApp

WhatsApp será canal operativo futuro, no parte de la fase actual.

Antes de enviar mensajes reales se debe definir:

- Números autorizados.
- Qué comandos se aceptan.
- Qué mensajes requieren aprobación.
- Logs de cada envío.
- Modo pausa.
- Control contra spam o errores.

## Memoria

La memoria futura de LÍA debe ser controlada.

Debe guardar patrones útiles, no datos innecesarios.

Ejemplos permitidos:

- Preferencias de agenda.
- Seguimientos abiertos.
- Decisiones recientes.
- Rutinas ejecutivas.
- Patrones de traslado.

Ejemplos delicados:

- Datos sensibles.
- Credenciales.
- Información privada innecesaria.
- Conversaciones completas sin justificación.

## Regla

LÍA debe recordar para asistir mejor, no para invadir.
