# Limitaciones y límites de alcance — v1.4.1

## Estado técnico real de la demo

Esta versión representa una **demo funcional/prototipo premium**.

## Qué está en modo mock

- Señales predictivas y recomendaciones.
- Datos de movilidad/ETA.
- Respuestas de comandos ejecutivos.
- Algunas relaciones del grafo cognitivo.
- Confirmaciones de acciones visuales.

## Qué NO está conectado todavía

- APIs externas en tiempo real.
- Backend operativo para ejecución transaccional real.
- Capa de autenticación endurecida para producción empresarial.
- Pipeline de auditoría/observabilidad para acciones reales.

## Qué NO debe prometerse al cliente

- Que existe automatización real de punta a punta.
- Que existe integración viva con sistemas corporativos.
- Que la plataforma ya está lista para despliegue productivo crítico.
- Que ya hay ejecución autónoma segura de acciones sensibles.

## Riesgos de sobrepromesa

- Pérdida de confianza en fases de validación técnica.
- Desalineación entre expectativa comercial y capacidad real.
- Fricción en procesos de compra y compliance.

## Mensaje correcto de límite

“LÍA O.S. v1.4.x valida la experiencia ejecutiva y la lógica de interacción. La activación de capacidades reales se realizará por fases, iniciando con planificación de integración en v1.5.0.”
