- `sourceDomain: agenda`
- `mode: readonly_source_runtime_rehearsal`
- `status: runtime_rehearsal_ready`
- `readsEnabled: true`
- `writesEnabled: false`
- `realConnectionActive: false`
- `credentialsLoaded: false`
