# Mock to Real Migration Plan

## Fase 1 — Mock premium actual

La experiencia visual y cognitiva funciona con datos simulados de alta calidad.

Criterio de avance:
- demo validada,
- UX estable,
- narrativa aprobada.

## Fase 2 — Mock con contratos

Los mocks se alinean a contratos de datos futuros.

Criterio de avance:
- contratos documentados,
- nombres estables,
- fuentes y destinos definidos.

## Fase 3 — Read-only real

Conectar solo lectura a sistemas seleccionados.

Criterio de avance:
- permisos mínimos,
- sin escritura,
- auditoría de consulta,
- manejo de errores.

## Fase 4 — Escritura simulada

Preparar acciones reales pero ejecutarlas en modo simulado.

Criterio de avance:
- confirmación visible,
- validación previa,
- resultado simulado,
- bitácora completa.

## Fase 5 — Escritura real con confirmación

Permitir escritura limitada en dominios de bajo riesgo.

Criterio de avance:
- permisos por rol,
- confirmación explícita,
- rollback lógico,
- monitoreo.

## Fase 6 — Automatización supervisada

La IA prepara acciones y el usuario aprueba paquetes.

Criterio de avance:
- reglas claras,
- límites por dominio,
- auditoría central.

## Fase 7 — Autonomía limitada futura

Solo rutinas de bajo riesgo con reglas preaprobadas.

Criterio de avance:
- métricas de confianza,
- trazabilidad completa,
- apagado seguro,
- revisión periódica.
