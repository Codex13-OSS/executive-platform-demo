# Next Phase Recommendations

## Recomendación principal

v2.2.0 — Cockpit Composition Layer / Read-Only Source Stack

## Objetivo

Agrupar las tarjetas técnicas relacionadas en una sola sección compacta:

- Read-Only Foundation
- Read-Only Connector
- Source Runtime
- Source Handshake

## Resultado esperado

El cockpit debe mostrar menos ruido técnico y más claridad ejecutiva.

## Propuesta visual

Una tarjeta o sección llamada:

Read-Only Source Stack

Debe mostrar:
- safe / locked
- 4 capas preparadas
- writes disabled
- credentials locked
- endpoint locked
- approval required
- pipeline visual compacto

## Detalle

Las tarjetas individuales pueden mantenerse como componentes, pero el cockpit debería mostrarlas agrupadas o resumidas.

## Fase posterior

Después de v2.2.0, se puede planear una fase de Connector Activation Review Pack antes de cualquier fuente real.
