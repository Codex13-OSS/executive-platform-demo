# UI Density and Layout Risk

## Riesgo actual

El cockpit ya contiene múltiples tarjetas de infraestructura. Aunque todas se ven bien por separado, juntas empiezan a competir por atención.

## Riesgos concretos

- Fatiga visual.
- Scroll más largo.
- Pérdida de jerarquía ejecutiva.
- Dificultad para explicar la demo rápidamente.
- Sensación de panel técnico en vez de sistema ejecutivo.

## Recomendación

Agrupar las tarjetas técnicas relacionadas en un bloque único:

Read-Only Source Stack

Contenido sugerido:
- Estado general: safe / locked.
- Pipeline: Foundation → Connector → Runtime → Handshake.
- Métricas compactas.
- Detalle expandible o vista secundaria.

## Qué no hacer todavía

No rediseñar todo el cockpit.
No borrar tarjetas sin una capa de composición.
No conectar fuentes reales antes de ordenar la presentación.
