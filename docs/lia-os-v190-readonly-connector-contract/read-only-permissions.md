# Read-Only Permissions

Permisos v1.9.0:

- Lectura de eventos.
- Lectura de disponibilidad.
- Lectura de metadatos.

Bloqueos obligatorios:

- Crear eventos.
- Actualizar eventos.
- Borrar eventos.
- Enviar invitaciones.
- Escribir metadatos.

Cualquier acción futura debe requerir confirmación humana explícita.
