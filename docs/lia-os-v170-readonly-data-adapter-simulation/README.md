# LÍA O.S. v1.7.0 — Read-Only Data Adapter Simulation

Objetivo: preparar una capa por dominios de adapters read-only para una evolución posterior hacia fuentes reales, sin conectar APIs reales en esta fase.

## Qué simula

- Adapters read-only por dominio.
- Estados de readiness y salud operativa.
- Señales de degradación controlada en UI.
- Self-check de seguridad de simulación.

## Qué NO conecta

- Sin APIs reales.
- Sin credenciales.
- Sin backend.
- Sin escritura.
- Sin auth/login adicional.
