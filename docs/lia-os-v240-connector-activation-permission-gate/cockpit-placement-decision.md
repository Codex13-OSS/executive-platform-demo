# Cockpit Placement Decision

## Ubicación

La tarjeta Connector Permission Gate se coloca después de Connector Activation Review.

## Motivo

Connector Activation Review muestra que el paquete está listo para revisión. Connector Permission Gate muestra que aun con la revisión lista, la activación continúa bloqueada hasta cumplir aprobaciones humanas y de seguridad.

## Principio

Avanzar hacia integración real sin activar fuente real, credenciales, backend ni escritura.
