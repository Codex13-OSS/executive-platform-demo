# Cockpit Layout Decision

## Antes

El cockpit mostraba varias tarjetas técnicas al mismo nivel:

- Read-Only Foundation
- Read-Only Connector
- Source Runtime
- Source Handshake

## Ahora

La vista principal muestra una composición compacta:

- Read-Only Source Stack

## Motivo

Reducir ruido visual, preservar jerarquía ejecutiva y preparar el cockpit para futuras integraciones sin hacerlo más pesado.
